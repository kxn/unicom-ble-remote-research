# 原始证据与迁移说明

## 文件

| 文件 | 内容 |
| --- | --- |
| `unicom-keymap-evidence.jsonl` | 用户按组操作的 HID 按键通知，含阶段标签 |
| `unicom-keymap.json` | 已人工对应的 29 键映射与语音附加报告 |
| `unicom-voice-evidence.jsonl` | 配对后订阅、FA/FB 实验指令、ATT 响应、原始通知和最终断开记录 |

语音记录中的 `handle` 为 ATT **特征值** handle；`value` 是原始通知/写入字节的十六进制，不包含独立 HID Report ID 前缀。`time` 为 Unix 时间，`monotonic` 为当时系统单调时钟，仅适合同次运行内求差。

语音成功实验标签：

- `fb_single_01_00`：序号 1–157，471 包。
- `fb_repeat_silence_speech`：序号 158–396，717 包；用户先安静，后说“现在测试联通遥控器”。人为按住时长是近似指令，准确通知时长以日志为准。
- `fa_single_01_00`：有 F8 单字节响应，没有 FC 连续数据。

证据包含原始的语音相关编码数据，不包含配对密钥。未将候选 WAV 当作成功录音发布。
